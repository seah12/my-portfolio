SHAINE NACE PORTFOLIO STARTER

WHAT IS INCLUDED
- index.html: the website content
- style.css: the design and layout
- script.js: small interactive features
- assets/: place your CV PDF and images here

HOW TO OPEN THE WEBSITE
1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html. It should open in your browser.
4. To edit the code, open the folder in Visual Studio Code (if available).

FIRST THINGS TO PERSONALIZE
1. In index.html, check your name, introduction, education, skills, projects and certificates.
2. Replace the sample project descriptions with accurate details. Do not label a proposed project as completed.
3. Add your own profile photo if you want. Put it in assets and ask for help adding it to the page.
4. Add your CV PDF to assets and name it Shaine-Nace-CV.pdf.
5. In script.js, replace YOUR-EMAIL@example.com with the email address you want to receive inquiries at.

IMPORTANT
This is a beginner-friendly FRONT-END starter. The contact form opens the visitor's email app. It does not yet save messages to a database and does not include a back-end/API. We can add a back-end after the basic website is working.
